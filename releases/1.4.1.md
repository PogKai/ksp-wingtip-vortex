# WingtipVortex 1.4.1 — Smooth wake

A patch release: the vortex tube no longer draws a sawtooth in a hard pull, and wing vapor is
spread more evenly over the wing.

## Fixed

* **The vortex rope zigzagged, seen from the side, in a hard pull (7+ g) at speed.** Each frame lays
  several rings between the last frame's position and the wingtip, and each ring's inward curve was
  aimed from its own position. Behind the tip the flight path is angle-of-attack off the airframe's
  axis, so every frame's rings were tipped toward the belly by an amount that reset each frame: one
  tooth per frame, as wide as the rope, growing with speed and angle of attack. The direction is
  now taken once per frame at the wingtip and blended across the rings in between
* **Spiral breakdown re-wound every frame at jet speed.** Its phase is now set when each stretch of
  rope is laid, so a spiral already drawn stays put
* **Wing vapor is spread evenly over the wing and sits on its suction surface.** Puffs are placed
  one per equal slice of the part's vapor instead of in independent random draws, thin vapor still
  gets faint puffs, and each puff rests on the skin instead of hanging half below it

## Install

Download `WingtipVortex_1.4.1.zip` and drop the `WingtipVortex` folder from it into `GameData/`. To
upgrade, replace the old `WingtipVortex` folder. No dependencies, no configuration, no GUI.

## Compatibility

* KSP 1.12.x. Stock aerodynamics or Ferram Aerospace Research (tested with FAR 0.16.2)
