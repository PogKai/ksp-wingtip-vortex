# Wingtip Vortex

A Kerbal Space Program 1.12.x mod that adds physics-driven **wingtip vortices, atmospheric contrails and raymarched wing vapor** to aircraft.

**Current version: 2.0.0** · KSP 1.12.x · no dependencies

---

## Features

- **Vortices on every aircraft:** procedural wake ropes respond to the lift each wing is actually producing, including nearby AI wingmen and BDArmory opponents
- **Raymarched wing vapor:** a soft volume over the wings, LEX and fuselage in a hard pull, shaped by airframe geometry, load, angle of attack and Mach number
- **Cobra and high-alpha support:** vapor follows the angle at which the wing meets the air instead of relying on G alone
- **Atmosphere-driven contrails:** persistent trails form from each body's own temperature and density rather than a fixed altitude band
- **Wake physics:** viscous core growth, ground effect and vortex breakdown
- **Stock and FAR support:** Ferram Aerospace Research is detected automatically and remains optional
- **Automatic setup:** install the folder and fly; an optional in-flight panel controls both effects and their intensity
- **Cross-platform shaders:** Windows, macOS and Linux AssetBundles are included in the release

---

## Install

Download the latest release, then copy the `WingtipVortex` folder from its `GameData` directory into your KSP `GameData/` folder. Delete an older WingtipVortex folder before upgrading.

See the [README](README.md) for usage, physics, compatibility, source credits and troubleshooting links.
